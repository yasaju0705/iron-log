IRON LOG PWA スターター

このフォルダはiPhone向けのWebアプリ（PWA）試作品です。
機能：筋トレ記録、前回記録、推定1RM、休憩タイマー、部位別ボリューム、週間メニュー、体重履歴、写真記録、簡易重量推移グラフ。
データはブラウザのlocalStorageに保存されます。現段階では端末・ブラウザ単位で、アカウント同期やクラウドバックアップはありません。Safariの履歴・Webサイトデータ消去等で消える可能性があるため、重要データは別途バックアップしてください。

iPhoneだけで公開する手順（GitHub Pages例）
1. Safariで https://github.com/ を開き、アカウントを作成またはログイン。
2. 新しいPublicリポジトリを作成（例 iron-log）。
3. Add file → Upload files から index.html、manifest.webmanifest、sw.js をアップロードして Commit。
4. リポジトリの Settings → Pages → Deploy from a branch → main / root を選択して保存。
5. 公開URL（https://ユーザー名.github.io/iron-log/）をSafariで開く。
6. 共有ボタン → ホーム画面に追加。
※公開にはHTTPSが必要。反映まで数分かかる場合があります。

注意
- これは初期試作品で、App Store公開用の完成版ではありません。
- 写真はブラウザ内に保存されます。容量制限やデータ消失に注意してください。
- PWAのオフライン動作・iOSのインストール挙動は実機確認が必要です。
- App Store配信には別途、ネイティブ化または審査要件を満たすラッパー等の検討、Apple Developer Program登録、プライバシー表示、審査対応が必要です。
